# Receiver privacy contract

Every field defaults off and can be changed independently:

- coarse location
- project names
- public GitHub repository URLs
- locally derived private-repository tech stacks
- brief project descriptions
- ad frequency and quiet hours
- subscription tier
- token-usage range
- total-session range
- accepted reward types
- minimum cash take-home

Warn that project names and public repository URLs can directly identify the person before bidding and require separate consent for that exposure.

For a private repository, inspect manifests locally and publish only allowlisted technology labels. Never publish its name, path, remote, filenames, source, commits, prompts, transcripts, contacts, secrets, or exact usage. Do not send rejected fields to logs or APIs.

Show the complete serialized outbound snapshot before activation. Pausing stops checks and new opportunities immediately, advances consent, and invalidates the prior version.
